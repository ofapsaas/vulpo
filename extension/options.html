Perfiles de conexión

# Formato: bridgeUrl token dominio1 dominio2 ... # Cada línea = un perfil. El orden define prioridad (first match wins). # Líneas que empiezan con # son comentarios. https://bridge.example.com YOUR_TOKEN_HERE *.example.com https://bridge.example.com ANOTHER_TOKEN *.other-example.com # Se puede usar "*" como dominio catch-all: https://your-bridge.example.com YOUR_TOKEN * https://another-bridge.example.com ANOTHER_TOKEN *.example.org

¿Cómo funciona?

Cuando abrís un tab en un dominio que matchea un perfil, Vulpo conecta con el bridge server de ese perfil. El agente puede ver y controlar ese tab (y solo los dominios de ese perfil). Si ningún perfil matchea, el tab está protegido.
